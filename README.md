🌿 ReadLanguage 2.0

Aprenda idiomas no seu ritmo, uma lição de cada vez!

📚 Sobre o projeto

O ReadLanguage é uma aplicação web de aprendizagem de idiomas, com interface responsiva para celulares e computadores.

✨ Funcionalidades

- 🌎 Cursos de inglês, espanhol, francês, alemão, italiano, japonês e português.
- 📖 Trilhas de aprendizagem organizadas em unidades e lições.
- 🧠 Exercícios interativos de vocabulário.
- ⭐ Sistema de XP e progresso.
- 🔥 Contador de sequência diária.
- 📚 Caderno de palavras favoritas.
- 🔄 Revisão de vocabulário.
- 🎯 Metas diárias personalizáveis.
- 📊 Histórico de atividades.
- 💾 Salvamento local do progresso.
- 📤 Exportação e importação de dados.
- 📱 Interface adaptada para dispositivos móveis.
- 🚫 Sem seção VIP.

🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage

🚀 Como publicar

1. Envie "index.html", "style.css", "app.js" e "README.md" para a raiz do repositório.
2. Abra Settings → Pages.
3. Selecione a branch "main" e a pasta "/ (root)".
4. Salve e aguarde a publicação.

🔒 Privacidade

Nesta versão, o progresso é armazenado no navegador do usuário. Não há contas, sincronização entre aparelhos ou banco de dados remoto.

📌 Estado do projeto

Versão inicial funcional. Novos cursos, exercícios, recursos de áudio e sincronização online podem ser adicionados futuramente.
